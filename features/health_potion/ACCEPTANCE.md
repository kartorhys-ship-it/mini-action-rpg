# Acceptance — Health Potion

- [x] One visible health potion appears at its configured room location.
- [x] Touching it below full health restores 30 health or the smaller missing amount.
- [x] Health never exceeds the configured maximum.
- [x] The HUD updates after healing.
- [x] A full-health player cannot waste the potion; it remains available.
- [x] A consumed potion is removed and cannot heal twice.
- [x] A dead player cannot be revived by the potion.
- [x] Slime contact/defeat, health HUD, gold pickup, and dummy tests continue to pass.
- [x] Godot editor import and headless runtime checks pass.
- [ ] The user can find and collect the potion in the graphical game.
- [ ] No inventory, hotkey, potion drop behavior, or unrelated feature is added.
