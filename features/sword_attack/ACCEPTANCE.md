# Acceptance — Sword Attack

- [ ] Attack action is bound to Space.
- [ ] Player initially faces down and updates facing on movement.
- [ ] Pressing attack starts an attack in the facing direction with visible slash feedback.
- [ ] Attack is active for the configured short window and then ends.
- [ ] Slash cue remains visible long enough to notice after the hit window ends.
- [ ] Cooldown prevents another attack until ready.
- [ ] A compatible target in range receives one damage call per swing, not repeated calls during the same swing.
- [ ] Targets outside the attack area are not damaged.
- [ ] Existing WASD/arrow-key movement remains unchanged.
- [ ] Project imports and launches without parser/runtime errors.
- [ ] No HUD, dummy, enemy, game-over flow, or debug input was added.
