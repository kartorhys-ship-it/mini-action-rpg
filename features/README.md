# Feature specifications

Each gameplay feature gets a small contract before implementation.

Recommended contents:

```text
features/<feature-name>/
├── SPEC.md
├── ACCEPTANCE.md
└── NOTES.md
```

`SPEC.md` defines purpose, behavior, dependencies, and explicit non-goals. `ACCEPTANCE.md` lists observable checks. `NOTES.md` records implementation decisions or playtest findings when useful.

The next feature is `main_scene`, corresponding to Milestone 1 in `docs/ROADMAP.md`.
