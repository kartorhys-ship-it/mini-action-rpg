# Acceptance — Player Movement

- [ ] WASD moves the player up, down, left, and right.
- [ ] Arrow keys provide the same movement controls.
- [ ] All eight movement directions work.
- [ ] Diagonal movement speed matches cardinal movement speed.
- [ ] The player stops when movement input is released.
- [ ] The player collides with all four room walls and cannot leave the room.
- [ ] The camera stays centered on the player during movement.
- [ ] Movement stops immediately when input is released; no acceleration or inertia is present.
- [ ] The project starts without GDScript parser or runtime errors.
- [ ] No features outside player movement were added.
